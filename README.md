# Portfolio

My personal portfolio website showcasing my skills, projects, and contact information.

## 🌟 Features

- **Responsive Design**: Works seamlessly on all devices
- **Smooth Animations**: Engaging hover effects and page load animations
- **Single Page Layout**: Easy navigation with smooth scrolling
- **Modern UI**: Clean and professional design with gradient effects

## 🛠️ Technologies Used

- HTML5
- CSS3 (with animations and transitions)
- Responsive design with media queries

```

├── css/

```

## 🚀 Getting Started

2. Open `index.html` in your browser
3. Enjoy the portfolio!
